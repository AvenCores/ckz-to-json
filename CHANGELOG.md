# Changelog

Формат - [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии - [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено
- встроенный интерактивный UI: запуск без аргументов в терминале показывает пошаговое меню,
  в котором доступны все возможности флагов (режим -e/-c, вход -i/папки/пакетный режим,
  способ выбора --no-dialog, --format, -o, --stdout, --iter, --key-bits, --tag-bits, --adata, -f, -q);
  после задачи — возврат в меню
- тест `TestNoArgsWithoutTerminal`: без терминаля и аргументов утилита не зависает, а завершается с подсказкой
- оформление интерактивного UI: очистка экрана при возврате в главное меню, баннер-рамка,
  «шаги» мастера, цветовая разметка (ANSI): пункты и номера меню, шаги, сводка,
  сообщения об ошибках (красный) и об успешном сохранении/сводке пакета (зелёный);
  цвета и очистка автоматически отключаются при перенаправлении вывода и на старых консолях Windows

### Изменено
- диалоги выбора файла ОС и список в терминале показывают ожидаемое расширение (`.ckz` или `.json`)
  вместо жёстко зашитого `.ckz`

## [1.1.0] - 2026-09-04

### Добавлено
- режим шифрования `--encrypt/-e`: JSON -> `.ckz` (параметры `--iter`, `--key-bits`, `--tag-bits`, `--adata`)
- `--check/-c`: проверка структуры `.ckz` и параметров записей без пароля
- форматы результата `--format json|csv|cookies` (CSV и Netscape `cookies.txt` для экспорта cookies)
- пакетная обработка: несколько файлов/папок аргументами или `-i` (несколько раз), итоговая сводка
- предупреждение о том, что пароль во флаге `-p` попадает в историю командной строки
- обнуление производного ключа и пароля в памяти после использования
- SHA256SUMS.txt в релиз-архивы, автоматические release notes по тегу
- синхронизация версии в ресурсах Windows (`.syso`) с версией сборки в `build.ps1`/`build.sh`/CI
- fuzz-тест AES-CCM (фаззер Go) и сквозные e2e-тесты CLI (шифрование/расшифровка/форматы/collision)

### Изменено
- сообщения CLI полностью на русском; пауза «Нажмите Enter» и при ошибках, и после сохранения
- `make release`/`build.*` помечают бинарники релизной версией

## [1.0.0] - 2026-09-04

### Добавлено
- расшифровка `.ckz` (PBKDF2-HMAC-SHA256 + AES-CCM, реализация только на stdlib) и экспорт в JSON
- выбор файла: диалог ОС / терминал / drag&drop / `-i`; пароль: ввод со звёздочками / `-p` / `CKZ_PASSWORD`
- несколько записей в файле (JSON и JSON-Lines); защита от перезаписи (`-f`)
- кросс-сборки linux/darwin/windows x amd64/arm64 (Makefile, build.ps1, build.sh, GitHub Actions)
- иконка и сведения о версии в свойствах exe (go-winres)
- 78 криптографических векторов от Python `cryptography` во встроенных тестах
